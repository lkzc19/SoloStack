<h1 align="center">SoloStack</h1>

<p align="center">
  <strong>MacOS 上的大数据组件本地管理器</strong><br />
  在本机安装、配置、启停、卸载大数据组件，全程图形界面
</p>

<p align="center">
  <sub>当前仅支持 Apple Silicon</sub>
</p>

## 支持的组件

| 组件 | 版本 |
|---|---|
| Hadoop | 3.5.0（单机伪分布式） |
| Kafka | 4.3.1（KRaft） |
