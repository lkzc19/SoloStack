# SoloStack UI 组件名称对照表

> **用途**：这是沟通"要修改哪个 UI 位置"时的**统一命名表**。修改请求请直接引用编号 + 名称，
> 例如：「**M2** 组件行改成…」「**CC3** 属性表单…」「**H2** 齿轮按钮…」。
> 编号与当前代码一一对应，改代码后需同步维护本表。

## 命名规则

- **首字母** = 区域：`H` header 顶栏 · `M` main 组件列表 · `F` footer 状态栏 · `O` 首次引导 · `CFG` 全局配置页 · `INST` 安装页 · `CC` 组件配置页 · `CL` 组件日志页
- **编号** = 区域内顺序；**小数点后** = 子元素（如 `M2.3` = 组件行里的第 3 个子元素）
- 括号内为**代码类名**，用于我定位；中文名是你在沟通时用的称呼

## ② M —— main 组件列表

| 编号 | 中文名 | 代码类名 | 说明 |
|---|---|---|---|
| M1 | 列表容器 | `.content` / `.comp-list` | 只显示**已安装**组件的列表（无模板占位） |
| **M2** | **组件行** | `.comp-row` | 白卡片，圆角 + 柔和阴影，hover 上浮；flex：灯｜信息｜按钮 |
| M2.1 | 状态灯 | `.led` | 圆点：running 绿 / partial 琥珀 / stopped 灰 / error 红 |
| M2.2 | 信息区 | `.comp-info` | 纵向排布名称 + 元信息 |
| M2.3 | 组件名称 | `.comp-name` | 组件名 |
| M2.4 | 元信息 | `.comp-meta` | 版本 + 状态，如 `v3.5.0 · 运行中` |
| **M2.5** | **操作按钮组** | `.row-actions` | 右侧三个按钮：[启动/停止]（组件级）[配置] [日志] |
| M3 | 空态 | `.empty` | 无组件时：HardDrive 图标 + "点击右上角 + 安装组件" |

> 组件行按钮：运行中/部分运行 → [停止]；已停止 → [启动]；[配置] → CC 页；[日志] → CL 页。

## ⑧ INST —— 安装页（view=install）

| 编号 | 中文名 | 代码类名 | 说明 |
|---|---|---|---|
| INST1 | 组件横条 tab | `.comp-tabs` / `.comp-tab` | 顶部横条按钮组，顺序前端写死（hadoop / kafka） |

| INST5 | 开始安装 | `.install-actions` | [开始安装] + spinner → 写临时 json → 下载解压 → 生成配置 → 删临时 json |

## 使用示例

- 「**M2** 组件行间距调大」→ 定位 `.comp-row`
- 「**M2.5** 把 配置 按钮改成图标」→ 定位 `.row-actions`
- 「**CC3** 属性表单改两列」→ 定位 `.prop-list`
- 「**CL3** 日志框行高调大」→ 定位 `.log-box`
- 「**INST3** 端口默认值改」→ 定位 `.port-grid`
