## EXT-01：已有组件新配置项追加

**影响范围**：Hadoop、Kafka 组件配置

随着使用深入，已有组件可能需要暴露更多配置项（如 Hadoop 的 YARN 资源配额、Kafka 的 Topic 默认参数等）。

**要求**：
- 新配置项需支持前端可视化编辑
- 配置项变更需正确回写到组件实际配置文件
- 保持与现有配置结构的兼容性

**待补充**：具体需要追加的配置项列表。
